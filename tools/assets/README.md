# Генераторы текстур

Скрипты, которыми сделаны картинки в `app/public/earth/`. Текстуры в репозитории
уже лежат — эти файлы нужны, чтобы можно было пересобрать их заново и не
вспоминать, откуда взялись числа.

| Скрипт | Что делает |
|--------|------------|
| `mk_earth_real.py` | Собирает `day/clouds/lights/water/normal.webp` из снимков NASA Blue Marble и карты высот: кроп, кодирование, нормаль из рельефа |
| `mk_normal.py` | Только нормаль из карты высот (сила 26, приглушение у полюсов) |
| `mk_landmask.py` | Маска суши 180×90 в base64 для шара из точек (`src/landmask.ts`) |
| `mk_earth.py` | Старый вариант синтетической Земли — оставлен для истории |

Исходники NASA — public domain. Пути к ним в скриптах абсолютные (временная
папка машины автора): правятся в одном месте, в начале файла.

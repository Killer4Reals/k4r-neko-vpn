# Отчёт 0.3 — что сделано после 0.2

Коротко: закрыл последний крупный пункт из твоих вопросов — блокировку при
обрыве, и поправил всё, что ты нашёл утром.

## 1. Окна консолей больше не выскакивают

Ты заметил: при заходе в «Защиту» на секунду открывается чёрное окно. Причина —
приложение спрашивало Windows о состоянии `winws2` через консольную программу,
и Windows показывала её окно. Теперь **все** консольные вызовы (проверка
состояния, поиск программ, запуск движка, запуск Zapret, запрос прав) идут
скрыто. Ни одного мигающего окна.

## 2. Кнопка «свернуть» прячет окно в трей

Раньше так работал только крестик. Теперь и «свернуть»: окно исчезает, значок
остаётся внизу справа, туннель продолжает работать — как у Zapret.
В настройках два отдельных переключателя, чтобы можно было выбрать любое
поведение: «Крестик — в трей» и «Кнопка «свернуть» — в трей».

## 3. Блокировка при обрыве: объяснение и что сделано

**Зачем она нужна.** Пока туннель работает — всё через сервер. Если туннель
падает, Windows возвращает обычный маршрут, и компьютер на секунды оказывается
«как без VPN»: настоящий адрес видно, заблокированные сайты не открываются.
Блокировка при обрыве запрещает этот откат.

**Как сделано.** Не через правила Windows (их легко оставить в системе и
остаться без интернета), а внутри нашего же движка: если движок упал, сразу
поднимается второй в режиме «держать» — адаптер тот же, но наружу всё
отклоняется, кроме локальной сети. Супервизор в это время пытается вернуть
настоящий туннель; получилось — «держащий» гасится.

**Проверено вживую:**

| Проверка | Результат |
| --- | --- |
| адаптер поднимается | да |
| наружу (1.1.1.1:443) | недоступно |
| локальная сеть (192.168.1.1:80) | доступно |
| после остановки наружу | снова доступно |

**Важная находка по пути.** Движок может быть «живым», но туннель при этом не
поднят — раньше приложение в таком случае показывало «Защищено». Теперь
подключением считается только состояние, где в журнале движка есть строка
`started at tun`. Нет строки — честная ошибка и включение «держащего» режима.

## 4. Счётчики трафика стали настоящими

Раньше «Скачивание 12.4 МБ/с» было нарисовано генератором случайных чисел.
Теперь приложение поднимает движку локальный эндпоинт со случайным паролем и
читает его счётчики раз в секунду. Проверка: скачал 20 МБ — счётчик движка
вырос ровно на 20 121 810 байт, на экране было 11 МБ/с.

## 5. ID устройства (HWID) и «UA»

- **HWID** — номер, по которому сервер подписки узнаёт устройство. Теперь он
  берётся из данных этого компьютера (`MachineGuid` + имя ПК): у тебя он
  постоянный, у другого человека с другим компьютером — свой. Если провайдер
  выдал конкретный номер, его можно вписать вручную.
- **UA (User-Agent)** — строка, которой приложение представляется серверу
  подписки. Некоторые провайдеры требуют конкретную — поле есть на экране
  «Серверы», в разделе заголовков запроса.

## Что не проверено

- Клик по значку в трее (возврат окна) и всплывающие уведомления Windows —
  нужно твоё участие, у меня значок в скрытой области.
- Запуск Zapret из приложения: консоль скрыта кодом, но сам запуск не трогал,
  чтобы не мешать твоему работающему Zapret.

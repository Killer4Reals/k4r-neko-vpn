# Функции: что есть, чего нет

Список ведётся, чтобы ничего не терялось. Состояние на **22.11.2026**:
Windows — **1.33.0**, Android — **1.19.0** (отдельный репозиторий).

Числа тестов: ядро **132**, интерфейс **173**, Android **231**.

## Туннель и соединение

| Функция | Где |
| --- | --- |
| VLESS + Reality + gRPC | весь клиент |
| WireGuard/WARP: ручной импорт `.conf` и авторегистрация бесплатного WARP | Серверы |
| Блокировка при обрыве (WFP, отдельный helper, переживает падение приложения) | Настройки, Главная |
| Автопереподключение и возврат после смены сети (Wi-Fi, кабель, выход из сна) | само |
| Переключение сервера, когда через туннель перестали идти данные | само |
| DNS туннеля: адрес, `https://` (DoH), `tls://` (DoT), каталог из 12 резолверов | Настройки |
| Блокировка IPv6 внутри туннеля | Настройки |
| Реальные счётчики трафика из движка, расход по дням | Главная, Статистика |
| Спидтест через выбранный узел | Серверы |
| «Мой IP» после подключения | Главная |
| Проверка утечек DNS | Настройки |

## Чего нет (и почему)

| Чего нет | Почему |
| --- | --- |
| Мультихоп (цепочка из двух стран) | Провайдер не даёт второго плеча; своя цепочка — отдельный движок и отдельный риск |
| Своя статистика по приложениям | Нужен ETW-сборщик на уровне ядра Windows: тяжело и спорно по приватности |
| Виджет на домашний экран Android | Отложено: сначала проверяем, как ведёт себя плитка в шторке на живых телефонах |
| Мини-окно «только статус» на ПК | Отложено: трей уже закрывает этот сценарий |
| iOS | Не планируется |

Это список вариантов, а не обещание: что из него нужно — решает владелец.

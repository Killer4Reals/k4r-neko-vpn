# Функции: что есть, чего нет

Список ведётся, чтобы ничего не терялось между версиями. Состояние на
15.11.2026, версия 1.0.0.

## Есть и проверено

| Функция | Где |
| --- | --- |
| Туннель VLESS + Reality + gRPC | весь клиент |
| Несколько подписок сразу, обновление по расписанию (1–48 ч) | Серверы |
| Ручная вставка `vless://` (одна или пачка строк) | Серверы → Импорт ссылки |
| Проверка живости серверов, отметка «не отвечает» | Серверы, Главная |
| Авто-выбор быстрейшего сервера | Главная, Серверы |
| Разделение по программам: «только выбранные» и «все, кроме выбранных» | Что идёт через VPN |
| Сканирование установленных программ и поиск с человеческими именами | Что идёт через VPN |
| Блокировка при обрыве (держащий режим) | Настройки, Главная |
| Автопереподключение | Настройки |
| DNS туннеля: адрес, `https://` (DoH), `tls://` (DoT) | Настройки |
| Блокировка IPv6 внутри туннеля | Настройки |
| Реальные счётчики трафика из движка | Главная |
| Горячая клавиша включения | Настройки |
| Автозапуск с Windows | Настройки |
| Крестик и «—» в трей, возврат окна | Настройки |
| Карточка-уведомление в углу окна | всё приложение |
| Три темы: тёмная, светлая, маскот | Настройки |
| Два языка: русский, английский | Настройки |
| Живой маскот: дыхание, пульс, свечение, качание | Главная |
| Чтение состояния чужого Zapret, без вмешательства | Защита туннеля |
| Экспорт журнала | Настройки, Журнал |
| ID устройства (свой или от провайдера) | Настройки |
| Проверка новой версии по файлу описания | Настройки |
| Установщик и портативная сборка | dist |

## Нет в приложении (кандидаты)

| Функция | Зачем |
| --- | --- |
| Остаток трафика и дата окончания подписки | провайдеры присылают это в заголовке `subscription-userinfo`; человек не должен считать вручную |
| QR-код подписки: показать свой и отсканировать чужой | перенос подписки на телефон или с телефона |
| Замер скорости (спидтест) через выбранный сервер | понять, что сервер медленный, а не интернет |
| Мой IP после подключения | видно, что реально сменился адрес |
| Статистика трафика за день/неделю | видеть расход, а не только текущую скорость |
| Резервная копия настроек (файл) | переезд на другой компьютер без потери списков |
| Скорость и загрузка серверов в процентах у провайдера | выбрать не только по пингу |
| Автообновление приложения | сейчас проверка есть, скачивание — вручную |
| Проверка утечек DNS | убедиться, что запросы не уходят провайдеру |

Это список вариантов, а не обещание: что из него нужно — решает владелец.

# Функции: что есть, чего нет

Список ведётся, чтобы ничего не терялось между версиями. Состояние на
16.11.2026: Windows — 1.2.0, Android — 0.2.0.

| Сканирование установленных программ и поиск с человеческими именами | Что идёт через VPN |

## Android 0.2.0: есть и проверено на устройстве

| Функция | Где |
| --- | --- |
| Туннель VLESS + Reality + gRPC или ws (тот же sing-box, но библиотекой) | весь клиент |
| «Защищено» только после живых данных через туннель | Главная |
| Подписка: ссылка, название, трафик, срок, список серверов с флагами | Главная |
| Перебор серверов при отказе (до трёх), «Авто-выбор» — в конце | Главная |
| Отклик сервера при выборе: «5 мс» или «нет ответа» | Главная |
| Мой IP после подключения | Главная → «Проверить IP» |
| Разделение по программам: «только выбранные» / «все, кроме выбранных» | Разделение |
| Защита при обрыве: трафик не уходит напрямую, кнопка «Вернуть интернет» | Настройки, Главная |
| DNS туннеля: адрес, DoH, DoT + каталог из 12 резолверов | Настройки |
| Блокировка IPv6 | Настройки |
| Три темы | Настройки |
| Язык: как в системе / русский / English | Настройки |
| Счётчики трафика от ядра | Главная |
| Журнал ядра в приложении (200 строк, без адресов серверов) | Настройки → Диагностика |
| Автозапуск после перезагрузки, плитка в шторке | Настройки |
| Постоянный `X-HWID` из `ANDROID_ID` | автоматически |

Чего на Android пока нет (кандидаты на паритет с ПК): несколько подписок сразу,
QR-код подписки, спидтест, статистика по дням, прокси для Telegram, резервная
копия настроек, проверка утечек DNS.

## Нет в приложении (кандидаты)

| Функция | Зачем |
| --- | --- |
| Остаток трафика и дата окончания подписки | провайдеры присылают это в заголовке `subscription-userinfo`; человек не должен считать вручную |
| QR-код подписки: показать свой и отсканировать чужой | перенос подписки на телефон или с телефона |
| Замер скорости (спидтест) через выбранный сервер | понять, что сервер медленный, а не интернет |
| Мой IP после подключения | видно, что реально сменился адрес |
| Статистика трафика за день/неделю | видеть расход, а не только текущую скорость |
| Резервная копия настроек (файл) | переезд на другой компьютер без потери списков |
| Скорость и загрузка серверов в процентах у провайдера | выбрать не только по пингу |
| Автообновление приложения | сейчас проверка есть, скачивание — вручную |
| Проверка утечек DNS | убедиться, что запросы не уходят провайдеру |

Это список вариантов, а не обещание: что из него нужно — решает владелец.

# Проверка на живой машине (чек-лист)

Пункты, которые нельзя проверить в CI: они требуют реального туннеля, прав
администратора и настоящей сети. Проходить сверху вниз, отмечать результат.

## 1. Установка и запуск
- [ ] Установить `K4R.Neko.VPN_1.14.0_x64-setup.exe` поверх предыдущей версии.
- [ ] Приложение запустилось, версия в настройках — 1.14.0.
- [ ] Настройки и серверы из прошлой версии на месте.

## 2. Туннель
- [ ] Подключиться к своему серверу — статус «подключено».
- [ ] Открыть любой сайт, проверить скорость (кнопка «Скорость»).
- [ ] Отключить VPN — интернет возвращается.

## 3. Kill-switch (нужны права администратора)
- [ ] Настройки → «Проверить kill-switch» → 7 проверок зелёные.
- [ ] Включить kill-switch, выключить VPN → интернет закрыт, сайты не открываются.
- [ ] Включить VPN → интернет появился.
- [ ] Перезагрузить компьютер с включённым kill-switch → после входа защита снова стоит.
- [ ] Выключить kill-switch → защита снята, в планировщике задачи «K4R Neko VPN kill-switch» нет.

## 4. Проверка утечек
- [ ] Настройки → «Проверка утечек» → IPv6: «не проходит» (при включённом блоке IPv6).
- [ ] Адрес выхода — не твой домашний IP.
- [ ] Отвечающий DNS — не адрес провайдера.

## 5. Оркестратор
- [ ] Подключиться, поработать 2–3 минуты.
- [ ] Настройки → в блоке оркестратора появились строки с процентами и именами серверов.
- [ ] «Сбросить обучение» очищает список.

## 6. Проверка «интернета нет»
- [ ] Подключиться к серверу, затем временно заблокировать его (или выдернуть сеть) —
      через ~30 секунд приложение должно переключиться на другой сервер и сказать об этом.

## 7. WARP
- [ ] «Серверы» → «Включить WARP» → появился профиль WARP с меткой «резерв».
- [ ] Выбрать WARP и подключиться — интернет работает.
- [ ] Вернуть основной сервер, WARP остаётся резервным.

## 8. Обновление
- [ ] Настройки → «Проверить» в блоке обновлений → «Установлена последняя версия».
- [ ] (Опционально) выйти из приложения, подождать баннер обновления — не должен появляться,
      если версия свежая.

## 9. Статистика
- [ ] Вкладка «Статистика»: за 7 дней видны столбики, «Сегодня» растёт при работе.
- [ ] Переключение на 30 дней работает.
- [ ] «Сбросить статистику» → «Точно сбросить» очищает цифры.

## 10. Узлы на планете и автопереключение
- [ ] На планете видны точки узлов; у быстрых зелёные, у тормозящих жёлтые.
- [ ] Наведение на точку даёт город и пинг: «Франкфурт · 38 мс».
- [ ] Через 10 минут после запуска замер обновился сам (точки не залипли серыми).
- [ ] Шапка списка серверов показывает «N из M отвечают».
- [ ] Настройки → «уходить с просевшего узла» включён: при разнице больше 40 мс
      приложение переключается и пишет «узел просел, перешёл на …».
- [ ] Тумблер выключен: переключений нет даже при явной разнице.

## 11. Игровой старт
- [ ] Запустить игру из списка «Программ через туннель» — приложение само
      выбирает узел по пингу и пишет «Игра запустилась: … — выбрал самый быстрый».
- [ ] Включить игровой режим тумблером — узел тоже выбирается по замеру.

## 12. Узлы и нажатие на планету
- [ ] Навести мышь на точку узла: подсказка «Франкфурт · 38 мс · нажми».
- [ ] Нажать точку: выбранный сервер в строке под шаром меняется, а VPN не
      включается и не выключается.
- [ ] Нажать шар мимо точек: VPN включается/выключается как раньше.
- [ ] Потянуть шар мышью: он крутится, но VPN не переключается.

## 13. Лимит устройств и номер устройства
- [ ] Настройки → «Номер устройства (HWID)»: нажатие на номер показывает
      «скопировано» и через полторы секунды возвращает номер.
- [ ] Вставить номер куда-нибудь (например в блокнот): это те же 12 символов.
- [ ] Если панель ответила «лимит устройств»: в сообщении есть кнопка
      «Сбросить HWID» и подсказка, что делать, если не помогло.

## 14. Автообновление
- [ ] С временно правленым манифестом со старой версией приложение НЕ предлагает
      обновление (сравнение числовое: 1.29.0 новее 1.9.0).
- [ ] С манифестом новее текущей версии предложение появляется.

## 15. История событий (1.30.0)
- [ ] Экран «История» открывается из меню, при первом запуске пишет «пока пусто».
- [ ] Подключиться → появляется «Подключился: <узел>» с временем.
- [ ] Отключиться → «Отключился».
- [ ] Переключить узел на главном → «Переключил узел: A → B».
- [ ] Раздел «Доступность узлов за неделю» показывает только узлы со сбоями.
- [ ] «Очистить историю» очищает список и после перезапуска он остаётся пустым.

## 16. Сценарии (1.31.0)
- [ ] На главном видны кнопки «Игры / Стрим / Работа».
- [ ] «Игры» → в настройках включён игровой режим, автопереключение выключено.
- [ ] «Стрим» → автопереключение включено.
- [ ] «Работа» → разделение по программам «только выбранные».
- [ ] Поменять одну настройку руками → подсветка сценария гаснет.
- [ ] Если туннель поднят, смена сценария перезапускает его (видно по «подключено» заново).

## 17. Проверка одной кнопкой (1.32.0)
- [ ] Настройки → «Проверить» показывает шесть пунктов.
- [ ] Без серверов первый пункт красный и с подсказкой «вставь ссылку подписки».
- [ ] Включить разделение «только выбранные» с пустым списком → пункт красный.
- [ ] «Скопировать отчёт» копирует текст с пометками [ok]/[!]/[x].

## 18. Звук (1.33–1.34)
- [ ] При подключении сначала «вдох», потом мотив: Азия — высокий, Европа — низкий.
- [ ] Звук выключен в настройках → тишина (никаких хвостов).
- [ ] После отключения туннеля звук не продолжается.

## Что делать с результатами
Любой красный пункт: Настройки → соответствующая кнопка «Скопировать отчёт»
(для kill-switch) или скриншот — и прислать. По логам: Настройки → «Экспорт логов».

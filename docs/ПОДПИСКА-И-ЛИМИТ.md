# Подписка не загружается: что проверить по порядку

Короткая памятка для случая «вставил ссылку, а серверов ноль». Порядок важен:
каждый следующий шаг имеет смысл только если предыдущий не дал ответа.

## 1. Ссылка и сеть

- Ссылка должна начинаться с `https://` и открываться в браузере. Если браузер
  показывает текст — это нормально, приложение читает тот же ответ.
- Домен провайдера может быть заблокирован. Тогда помогает включённый туннель
  к любому рабочему узлу: приложение само повторяет запрос через туннель
  (в настройках это ничего не требует).
- Синтетический ответ панели не должен подменяться прокси: если в ответе нет
  строк `vless://` / `vmess://` / `trojan://`, дело не в приложении.

## 2. Лимит устройств (самое частое)

Панель считает устройства по номеру HWID и на каждое выдаёт слот. Когда слоты
кончились, ответ приходит с кодом 200, но с заголовками:

```
x-hwid-active: true
x-hwid-limit: true
x-hwid-max-devices-reached: true
```

а тело — короткая заглушка `vless://00000000-0000-0000-0000-000000000000@0.0.0.0:1`.

Приложение показывает это как «провайдер: лимит устройств исчерпан» и **не
повторяет запрос само** — иначе оно бы бесконечно долбило панель.

Что делать:

1. Нажать «Сбросить HWID» прямо в сообщении об ошибке (или в настройках).
   Приложение возьмёт новый номер и сразу попробует загрузить список снова.
2. Если панель всё равно отказывает — зайти в кабинет провайдера и освободить
   старое устройство. Номер для этого копируется нажатием: «Номер устройства
   (HWID)» в настройках.
3. Переустановка приложения **не** помогает: номер устройства считается из
   системы, а не из файлов приложения, и переустановка его не меняет.

## 3. Срок и трафик

- «подписка истекла» / `x-sub-expire` в прошлом — продлевать у провайдера.
- «трафик исчерпан» — то же, лимит трафика на стороне панели.
- Счётчики трафика в приложении считают только текущую сессию и не спорят с
  панелью: ориентируйтесь на цифры кабинета.

## 4. Провайдер сменил формат

Если панель начала отдавать Clash/YAML вместо списка ссылок, приложение скажет
об этом отдельно. Это не поломка приложения: нужен формат base64-списка или
обычные ссылки.

## 5. Совсем ничего не помогло

Пришлите строку из «Диагностики» (Настройки → Диагностика → Показать лог).
Адреса серверов в лог не попадают, ссылка подписки тоже: там только коды
ответов и текст ошибок.

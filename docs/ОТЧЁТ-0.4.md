15.11.2026. Версия 0.4.0 — последняя для Windows перед переходом на Android.

| Что | Зачем |

## Что осталось непроверенным

- Туннель в режиме «Только выбранные» после сборки 0.4.0. Проверка требует
  поднять адаптер, а это на время рвёт соединение — ждёт паузы в игре. Код
  маршрутизации между 0.3 и 0.4 не менялся, менялся только интерфейс.
- Автообновление подписки по расписанию в реальном времени (интервал 12 ч).
  Логика проверяется раз в минуту сравнением метки времени; вживую ждать
  двенадцать часов нецелесообразно, проверено чтением кода и прогоном
  «просрочено → обновляет» при пустом списке.

## Известные ограничения

- Проверка обновлений требует **публичную** ссылку на файл описания версии.
  Приватный репозиторий отдаёт файл только с токеном, поэтому для авто-проверки
  нужен либо отдельный публичный адрес, либо ручное поле (сейчас поле пустое и
  кнопка честно говорит, что адрес не задан).
- Блокировка при обрыве работает на уровне маршрутов и правил движка, а не
  драйвера WFP. Этого достаточно для «утечка не пройдёт мимо интерфейса», но
  это не тот же уровень, что у коммерческих клиентов с драйвером.
- Установщик не подписан сертификатом: Windows покажет «Неизвестный издатель».

## Что это значит

Функционально Windows-версия закрыта: туннель, разделение по программам,
блокировка при обрыве, DNS, подписки, трей, горячая клавиша, темы, два языка,
обновление подписки, проверка версий, установщик и портативная сборка —
на месте и проверены.

Следующий крупный шаг — Android. Там другая архитектура: `VpnService` вместо
TUN через WinAPI, ядро остаётся на Rust, интерфейс придётся собрать заново.

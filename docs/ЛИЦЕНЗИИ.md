# Чужие работы внутри проекта

Мы используем чужой код и чужие картинки, и это записано здесь, чтобы потом не искать.

## Флаги стран — `app/public/flags/*.svg`

- Набор **flag-icons** (https://github.com/lipis/flag-icons), лицензия MIT.
- Взяты только файлы `4x3/<код>.svg`, ничего не перерисовано.
- Зачем: Windows не рисует флаги-эмодзи (показывает две буквы), поэтому флаг — отдельный SVG.

## Ядро туннеля — `sing-box`

- **sing-box** (https://github.com/SagerNet/sing-box), лицензия GPL-3.0.
- В репозитории бинарника нет: `scripts/fetch-engine.ps1` скачивает его при сборке.
- Приложение не меняет sing-box, а запускает отдельным процессом со своим конфигом.

## Оболочка и интерфейс

- **Tauri 2** — MIT/Apache-2.0, **React 19** — MIT, **Vite** — MIT.
- Иконки в интерфейсе нарисованы в проекте (`app/src/icons.tsx`), стоковых наборов нет.

## Маскот

- Нарисован для проекта, промпты и исходники лежат в `art/`.
- Сторонние изображения в интерфейсе не используются.

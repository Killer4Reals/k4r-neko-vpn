# Отчёт за ночь 15.11.2026 — версия 0.2

Коротко: то, о чём ты написал перед сном, исправлено. Приложение проверено
вживую на настоящем сервере, собраны портативная версия и установщик.

## Что было не так на экране «Что идёт через VPN»

1. **Список был забит программами, которые ты не добавлял.**
   Причина: программы со сканирования и твой выбор хранились в одном списке,
   и всё найденное автоматически считалось «через VPN».
   Теперь это два разных списка: найденное — только для поиска, а хранится и
   показывается только то, что ты сам выбрал. По умолчанию — пусто, с подсказкой.

2. **Поиск находил не всё.** Раньше смотрели только те программы, что прописаны
   в реестре Windows или уже запущены. Теперь читаются ярлыки меню «Пуск»,
   запущенные процессы и список установленных программ — 107 штук вместо 74,
   и с человеческими именами («Discord», а не `discord.exe`).

3. **Выбор не запоминался на вид.** Теперь запоминается: выбрал Discord «через
   VPN», перезапустил приложение — он на месте. Проверено, скриншот есть.

## По твоим просьбам этим утром

- **Окна winws2 и sing-box больше не вылазят.** Оба процесса запускаются
  скрыто, без чёрного окна консоли.
- **При выходе из приложения оба процесса закрываются сами.** Проверено:
  подключил туннель, закрыл приложение — движок исчез вместе с ним, виртуальный
  адаптер убрался, интернет вернулся напрямую.
- **Круг с маскотом стал кнопкой.** Нажатие на круг включает и выключает VPN,
  маскот больше не выходит за границы круга. Рядом добавил обычную кнопку
  «Включить VPN» / «Отключить VPN», потому что круг не все читают как кнопку.

## Что ещё поправил по пути

- **Честный индикатор Zapret.** Плашка «Защита туннеля» на главном экране
  показывала «включено» всегда. Теперь показывает реальное состояние. Чужой
  winws2 (твой) приложение только читает и никогда не останавливает.
- **Автопереподключение проверено в бою**: убил процесс туннеля руками —
  через 2 секунды поднялся новый, интернет через сервер не прервался.
- **Разделение по программам проверено в бою**: один и тот же файл, но под
  разными именами — один ушёл через Финляндию, второй остался на прямом
  маршруте. Работает одновременно.
- **Блокировка IPv6 чинила проблему исключённых программ.** Раньше программа,
  отправленная «напрямую», теряла IPv6-соединения. Порядок правил исправлен.
- **Туннель с выходами:** Финляндия 213.165.58.67, Лондон 167.104.223.23,
  Германия 109.120.137.30, Польша 144.31.1.106. Нидерланды сегодня не отвечали
  (это сервер, не приложение).
- Убрал мусорные надписи в Журнале и на экране Серверов (`state: idle`, `demo`).
- Журнал больше не показывает цветовые коды движка (`[36mINFO[0m`) — только текст.
- Автозапуск по умолчанию выключен: приложение не прописывается в систему без
  твоего ведома, галочка в Настройках работает и проверена.
- Переключатель «Блокировка при обрыве» больше не притворяется: он честно
  помечен «появится в следующем обновлении», а выбор запоминается.

## Что готово к запуску

- Портативная версия: `dist/K4R-Neko-VPN/` (папка) и
  `dist/K4R-Neko-VPN-0.2-portable.zip` (35 МБ).
- Установщик: `app/src-tauri/target/release/bundle/nsis/K4R Neko VPN_0.2.0_x64-setup.exe`
  Проверен: тихая установка, запуск, удаление — следов не остаётся.

## Что честно не проверено

- Всплывающие уведомления Windows: код есть, но показ нужно увидеть глазами.
- Клик по значку в трее для возврата окна (прячется по крестику — проверено).
- Настоящая блокировка трафика при обрыве (WFP) — это следующий этап 0.3.

## Что стоит сделать тебе утром

1. Запустить `dist/K4R-Neko-VPN/K4R Neko VPN.exe` от администратора.
2. Проверить трей: крестик → окно спряталось, клик по значку → вернулось.
3. Проверить, что приходит уведомление при подключении.
4. Сказать, какие программы хочешь видеть в списках по умолчанию — сейчас пусто.

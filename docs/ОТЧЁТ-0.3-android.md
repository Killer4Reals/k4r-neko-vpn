# Ночь 16.11.2026 — Android 0.3.0 и Windows 1.2.1

## Android 0.3.0 (APK: `dist/K4R-Neko-VPN-0.3.0-android.apk`)

Что появилось за ночь:

- **Несколько подписок**: плашки на главной, «Добавить подписку», «Забыть эту»,
  действующая запоминается. Старая одиночная подписка переносится сама.
- **Трафик по дням**: история за 30 дней, столбики за неделю, «сегодня» и
  «за 7 дней». Цифры — из счётчиков ядра.
- **Спидтест через туннель**: 5 МБ, мбит/с, цифры обновляются во время замера.
- **Резервная копия настроек** в JSON и восстановление из файла.
- **Отклик всех серверов** одной кнопкой (по три соединения за раз).
- **Ссылка подписки**: «Копировать» и «Вставить из буфера» (буфер читается
  только по нажатию).
- **Остановку ядра видно**: если ядро умирает после подключения, приложение
  переходит в «Ошибка» и держит трафик, а не показывает «Защищено».
- **Причина заглушки провайдера — действием**: «предел устройств» → «удалите
  лишнее устройство в кабинете и нажмите Load», «истекла» → «продлите».
- **Исправлено разделение по программам**: пустой выбор снова значит «все
  приложения» (приложение больше не добавляет себя в список, когда ничего не
  выбрано).

## Что проверено на живом туннеле

Поднят свой сервер sing-box на ПК (VLESS, `10.0.2.2:8443`), эмулятор Pixel 6:

| Проверка | Результат |
| --- | --- |
| Подключение | «Защищено» только после ответа данных |
| Адрес выхода | показывается адрес через туннель, а не домашний |
| Счётчики ядра | 11.7 КБ → 4.8 МБ после спидтеста |
| Спидтест через туннель | 6.7 Мбит/с |
| Учёт по дням | «Сегодня 4.8 МБ», «За 7 дней 4.8 МБ» |
| Отказ сервера | «Ошибка» + блокировка; запрос из приложения не проходит |
| «Вернуть интернет» | сеть возвращается, ложной ошибки нет |
| Выключение | состояние «Off», VPN-интерфейса в системе нет |
| Журнал ядра | «пробуем …», «туннель поднят на …», без адресов серверов |

## Windows 1.2.1 (`dist/K4R Neko VPN_1.2.1_x64-setup.exe`, portable ZIP)

Пересобрано с исправлением: ответ-заглушка провайдера («приложение не
поддерживается», предел устройств) больше не сохраняется вместо списка серверов;
флаги стран не путают страну со словом («It works» перестало быть Италией).

## Тесты

- Android: **103** юнит-теста на JVM (`./gradlew testDebugUnitTest`), все зелёные.
- Ядро ПК: **40** тестов Rust (1 помечен `ignored`).
- Интерфейс ПК: **25** тестов (`npm test`).

## Что не проверено и почему

- **Настоящая подписка провайдера**: слот устройств занят (5 из 5), провайдер
  отдаёт заглушку «Достигнут предел количества устройств». Нужно удалить лишнее
  устройство в кабинете — после этого «Load» зарегистрирует телефон сам
  (HWID считается из `ANDROID_ID` и переустановку не меняет).
- **Спидтест на быстром канале**: исправлен случай, когда файл скачивается
  раньше «минимального» срока, но проверить на канале быстрее 60 Мбит/с здесь
  нечем — эмулятор столько не даёт.
- **Приёмка на телефоне**: APK подписан тем же ключом, что и раньше
  (`CN=K4R Neko VPN`), ставится поверх 0.2.0.

## Как поставить

```
adb install -r dist/K4R-Neko-VPN-0.3.0-android.apk
```

Ключ подписи: `%LOCALAPPDATA%\Android\keys\k4r-release.jks` (в репозиторий не
попадает, терять нельзя).

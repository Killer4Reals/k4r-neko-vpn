# ADR-001: Архитектура K4R Neko VPN (0.1 → 1.0)

Дата: 2026-11-14
Статус: принято, требует замены на ADR-002 при переходе на чистое Rust-ядро

## Контекст

Клиент должен: работать на Windows из портативного файла, ходить через подписку
(VLESS/Reality и совместимые), уметь split tunneling по приложениям, работать в
связке с Zapret 2 Dev, быть локализованным (ru/en) и выглядеть как продукт, а не
как сгенерированный шаблон. Срок первой рабочей версии — 1–3 дня.

Факты, полученные на машине владельца (проверено, не предположение):

- Подписка отдаёт **Xray JSON** (Happ-формат) с `inbounds: socks:10808, http:10809`
  и `outbounds: vless`, а также **Clash YAML** при другом User-Agent.
- Провайдер фильтрует клиентов: чужому User-Agent отдаётся заглушка
  (`uuid: 00000000-…`, `server: 0.0.0.0:1`).
- Zapret 2 Dev стоит в `Documents\Zapret\Dev` в профиле владельца, активный
  пресет `general ALT9 1.10.3 (game filter).txt`, запуск через `winws2.exe`,
  пресеты — текстовые файлы с `--new`-профилями, `--lua-desync`, hostlist.

## Решение

1. **UI: Tauri 2 + React 19 + TypeScript**, `decorations: false`, свой заголовок.
   Причины: WebView2 уже в системе (проверено, 157.x), размер сборки на порядок
   меньше Electron, прямой доступ к Rust для команд ядра. Отказались от:
   Electron (тяжелее, лишний Node-рантайм), Slint/egui (слабее контроль над
   анимацией и типографикой), нативного WinUI (привязка к Windows).

2. **Владелец логики — Rust** (`src-tauri`), а не фронтенд. UI только рисует и
   отправляет команды. Причина: правила split tunneling, kill switch и запуск
   Zapret должны жить в привилегированном процессе, а не в WebView.

3. **Пакетный движок в 0.1 — sidecar** (отдельный процесс), управляемый из Rust.
   Причина: собственный TUN + VLESS + Reality + UDP за 72 часа — гарантированный
   провал по стабильности. Отказались от «сразу всё на boringtun», потому что
   подписка владельца — VLESS, а не WireGuard: boringtun для неё бесполезен,
   нужен Xray-совместимый транспорт.

4. **Split tunneling — по имени процесса** (routing rule `processName`), а не
   через WFP-фильтры. Причина: дешевле, переносимо, проверяемо логами. WFP
   остаётся для kill switch.

5. **Zapret — внешний компонент, не вшитый в инсталлятор.** Причина: WinDivert
   под LGPLv3, плюс меньше ложных срабатываний антивирусов. Пресеты читаем и
   пишем как файлы; активный пресет владельца берём за эталон.

6. **Секреты**: ключи подписки не попадают в логи; экран журнала показывает
   редакцию (`ADR-001` требование, реализуется в слое службы).

## Последствия

- Плюс: рабочая версия за дни, а не недели; дизайн не ограничен нативными
  контролами; один UI на Windows и Android (Flutter-клиент повторит дизайн-токены).
- Минус: два процесса (UI + движок), нужен контракт IPC и надзор за sidecar
  (перезапуск, health-check).
- Долг: миграция пакетного движка на Rust. Критерий перехода — ADR-002 и
  зелёные тесты на: handshake, MTU 1280–1420, DNS-leak, обрыв, смену сети.

## План отката

1. `git revert` коммита фичи — история линейная, каждый экран и подсистема
   отдельным коммитом.
2. Sidecar выключается флагом в конфиге, приложение остаётся работоспособным
   (UI + импорт подписок + журнал).
3. Zapret отключается независимо: режим «Защита туннеля» не влияет на сам
   туннель.

# ADR-002. Разделение по приложениям: пустой список по умолчанию

Дата: 15.11.2026, версия 0.2.0

## Проблема

В 0.1 экран «Что идёт через VPN» строился так: при старте сканировались
установленные программы, все они попадали в общий список, и у всех стоял
переключатель «через VPN». Владелец открыл экран и увидел 70+ программ,
которые он не добавлял, а поиск не находил половину установленного.

Три причины:

1. Список сканирования и список выбора были одной сущностью (`list`).
2. Сканирование не видело программы, у которых нет записи в App Paths
   и которые не запущены (ярлыки Пуска, установленные игры, portable-сборки).
3. Имена брались из имени файла: `browser.exe` вместо «Яндекс Браузер».

## Решение

**Каталог и выбор — разные вещи.**

- `catalog` — всё, что нашлось на компьютере. Только для поиска, не сохраняется.
- `chosen` — то, что владелец явно отправил в VPN или напрямую. Только это
  пишется в `state.json` (`split: [{exe, name, via}]`).
- По умолчанию `chosen` пуст: два пустых столбца и подсказка.
- Список из 100+ программ показывается только по кнопке «Показать все программы»
  или при вводе в поиск.

Сканирование переписано: один проход PowerShell собирает ярлыки Пуска
(читаемое имя), запущенные процессы (`Description`) и записи удаления
(`DisplayName`/`DisplayIcon`), плюс App Paths из реестра. Имя выбирается в
таком порядке: ярлык Пуска → описание процесса → имя из реестра → имя файла.
Мусор (обновляторы, установщики, telemetry, `\windows\`, `\temp\`) отсеивается.

Миграция: `schema = 2`. Файл, записанный 0.1, при первом чтении теряет `split`
целиком — там не было ни одного настоящего выбора. Дальше выбор сохраняется.

## Альтернативы и почему нет

- **Оставить общий список, но снять галочки по умолчанию.** Экран всё равно
  показывает 107 строк, в которых ничего не выбрано: визуальный шум, та же
  жалоба. Отклонено.
- **Хранить весь каталог в state.json.** Файл состояния растёт, при смене
  набора программ появляются призраки удалённых приложений. Отклонено.
- **Разделять по пути к exe, а не по имени файла.** Движок sing-box на Windows
  матчит `process_name` по имени файла; путь в правилах не работает. Отклонено.
- **Сканировать каждый раз при открытии экрана.** 1 секунда PowerShell на
  каждое открытие. Каталог берётся один раз при запуске приложения.

## План отката

Вернуть `split` в состояние 0.1 можно, откатив `schema` до 1 и вернув старый
экран: данные в `state.json` совместимы (поле `name` имеет `#[serde(default)]`,
старый клиент его проигнорирует).

## Проверка

- Пустой список при первом запуске — проверено вживую (скриншот).
- Поиск «discord» → «В VPN» → перезапуск → Discord остался в списке «Через VPN».
- Разделение по процессам проверено на живом туннеле: один и тот же `curl`,
  скопированный как `curltest.exe`, ушёл через туннель (выходной IP финского
  сервера), а исключённый `curl.exe` остался на прямом маршруте (IP провайдера).
- Юнит-тест `store::tests::old_scan_dump_is_dropped_once`.

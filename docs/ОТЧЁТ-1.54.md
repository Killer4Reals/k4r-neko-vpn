# Отчёт 1.54.0

Дата: 26.11.2026, ночная смена. Владелец ушёл спать, работа доведена автоматизацией.

## Что в релизе

- WARP удалён полностью: модуль, команда, кнопка, ключи; старые профили «warp-»
  отфильтровываются при загрузке. Обычный WireGuard .conf остался.
- Zapret без «Zapret 2» и без отдельной программы: каталог пресетов из папки
  Zapret, теги «Игры / Видео / Discord / QUIC», методы обхода, фильтры,
  «Применить», полоса состояния с лампой, PID и кнопкой запуска/остановки.
  Сцена боя удалена вместе с кадрами и звуками.
- Настройки: 4 вкладки, поиск по всем сразу, скрываются и карточки, и
  несовпавшие строки; вкладка запоминается.
- История: 28 отрезков по 6 часов на узел, легенда метро, пустые состояния
  с маскотом.
- Плавность: canvas-ы (глобус, карта, планета) не рисуются вне экрана и в
  скрытом окне; аврора не перерисовывается во время прокрутки; строки списка
  серверов получили content-visibility; sticky-вкладки без backdrop-blur.
- Вес: удалены неиспользуемые кадры боя и фон (~1,3 МБ).

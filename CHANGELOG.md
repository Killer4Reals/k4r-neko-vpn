# Что менялось

## Android 0.1.0 — туннель на телефоне

- **Настоящий VPN, а не заглушка.** Kotlin + Compose + собранный из исходников
  `libbox.aar` (sing-box 1.14.4): ядро просит у системы TUN, `VpnService`
  отдаёт файловый дескриптор, дальше ядро само разбирает трафик.
- Проверено живьём на эмуляторе (Android 15) с настоящей подпиской:
  **внешний адрес меняется на адрес сервера** (178.17.61.170 против домашнего
  185.59.245.245), то есть трафик действительно идёт через VLESS/REALITY.
- **«Защищено» только по факту**: после старта ядро должно ответить живым
  запросом наружу. Не ответило — состояние «Ошибка» и причина словами, а не
  зелёная галочка «на всякий случай». Если провайдер вернул заглушку
  «Приложение не поддерживается» (адрес 0.0.0.0:1), она показывается как есть.
- **Три экрана**: главная (маскот, состояние, подписка, «Твой IP», список
  серверов с флагами), «Разделение» (реальные установленные программы с
  иконками, режим «только выбранные / все кроме выбранных»), «Настройки»
  (три темы, каталог DNS как на ПК, блокировка IPv6, версия ядра).
- **Три темы** — ночь, неон, день; выбор сохраняется.
- **DNS-каталог из Windows-версии** перенесён один в один: 12 резолверов,
  у каждого три плашки IP / DoH / DoT, выбранный способ подсвечен.
- Чего пока нет: автозапуска после перезагрузки, плитки в шторке, счётчиков
  трафика в интерфейсе и переключателя языка внутри приложения (язык берётся
  из системы). Это следующий шаг, а не «сделано».

## 1.2.0 — флаги и каталог DNS

- **Флаги стран вместо приписок** в списке серверов и на главном экране.
  Провайдер присылает имена вида «🇫🇮 Финляндия»; код страны достаём из имени,
  а сам флаг — свой SVG-файл (`app/public/flags`, набор flag-icons, MIT).
  Windows флаги-эмодзи рисует буквами, поэтому эмодзи из имени убираем.
- **Каталог DNS с категориями**: «Быстрые без фильтров», «Без рекламы и
  трекеров», «Против вирусов и фишинга», «Семейные» и «Свой адрес».
  У каждого резолвера три плашки — **DoH / DoT / IP**: нажал и всё, адрес ушёл
  в настройки. Есть поиск по названию и адресу, строка «сейчас в настройках»
  и короткая легенда, чем DoH отличается от DoT.
- Строка DNS-сервера переехала под переключатель «Через туннель / Системный»,
  чтобы порядок в настройках читался сверху вниз.
- Починен настоящий баг: **выбранный пресет Zapret и переключатель прокси для
  Telegram не сохранялись** между запусками — сохранение не следило за ними.
- **Новый маскот в четырёх состояниях**: спит на облаке (покой), щит вокруг
  (защищено), сидит обняв колени (обрыв), за щитом с замочной скважиной
  (блокировка при обрыве). Плюс картинки для «подписки ещё нет», пустого
  разделения и боковая картинка установщика.
- Тесты: 38 (добавлены на арифметику дневного расхода).

## 1.1.0 — то, чего не хватало

- **Остаток трафика и срок подписки** из заголовка `subscription-userinfo`:
  «израсходовано 65,4 ГБ (без лимита) · до 05.12.2026 (20 дн.)».
- **Твой IP** на главном экране: адрес, который видят сайты, и кнопка проверки.
- **QR подписки** — рисуется локально, ссылка не уходит на сторонние сервисы.
- **Копия настроек** одним файлом в «Загрузки» и возврат из копии.
- **Проверка утечек DNS** через `whoami.akamai.net`: видно, какой резолвер
  отвечает сайтам — свой зашифрованный или провайдерский.
- **Замер скорости** честный: скачивает 10 МБ и считает байты в секунду.
- **Расход по дням** — сколько прошло через туннель, хранится два месяца.
- **Прокси для Telegram** внутри туннеля (SOCKS5 на 127.0.0.1:1354) — то же,
  что даёт Zapret своим прокси на 1353, только через наш сервер.
- **Вкладка «Защита туннеля» теперь показывает настройки самого Zapret**:
  DoH включён или нет, его прокси и порт — рядом с нашими аналогами.

## 1.0.0 — первая релизная версия для Windows

Первая версия, которую можно ставить людям. Всё, что ниже, проверено на живой
машине: подключение, разделение по программам, блокировка при обрыве,
переподключение, установка и удаление.

**Туннель**
- VLESS + Reality + gRPC через sing-box, несколько подписок, выбор сервера.
- Проверка живости серверов параллельно; не ответивший помечается «не отвечает».
- Автопереподключение при обрыве, до трёх попыток.

**Разделение по программам**
- Два режима: «Только выбранные» и «Все, кроме выбранных».
- Локальная сеть и принтер остаются локальными в любом режиме.
- Пустой список «В VPN» — отказ подключения, а не фиктивная защита.

**Блокировка при обрыве**
- Движок падает — поднимается «держащий» режим: наружу ничего не уходит,
  локальная сеть работает. Откат — один переключатель, следов в системе нет.

**DNS**
- Свой резолвер внутри туннеля: адрес, `https://` (DoH) или `tls://` (DoT).

**Настройки и мелочи**
- Автообновление подписки: 1/3/6/9/12/24/48 часов или вручную.
- Проверка новой версии по файлу с описанием.
- Горячая клавиша, автозапуск, крестик и «—» в трей, карточка-уведомление.
- Три темы (тёмная, светлая, маскот), два языка (ru/en), экспорт журнала.
- Свой ID устройства, счётчики трафика из движка, а не нарисованные.

**Zapret рядом**
- Приложение читает состояние чужого `winws2` и никогда его не трогает.

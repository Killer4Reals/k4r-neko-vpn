# Что менялось

## 1.0.0 — первая релизная версия для Windows

Первая версия, которую можно ставить людям. Всё, что ниже, проверено на живой
машине: подключение, разделение по программам, блокировка при обрыве,
переподключение, установка и удаление.

**Туннель**
- VLESS + Reality + gRPC через sing-box, несколько подписок, выбор сервера.
- Проверка живости серверов параллельно; не ответивший помечается «не отвечает».
- Автопереподключение при обрыве, до трёх попыток.

**Разделение по программам**
- Два режима: «Только выбранные» и «Все, кроме выбранных».
- Локальная сеть и принтер остаются локальными в любом режиме.
- Пустой список «В VPN» — отказ подключения, а не фиктивная защита.

**Блокировка при обрыве**
- Движок падает — поднимается «держащий» режим: наружу ничего не уходит,
  локальная сеть работает. Откат — один переключатель, следов в системе нет.

**DNS**
- Свой резолвер внутри туннеля: адрес, `https://` (DoH) или `tls://` (DoT).

**Настройки и мелочи**
- Автообновление подписки: 1/3/6/9/12/24/48 часов или вручную.
- Проверка новой версии по файлу с описанием.
- Горячая клавиша, автозапуск, крестик и «—» в трей, карточка-уведомление.
- Три темы (тёмная, светлая, маскот), два языка (ru/en), экспорт журнала.
- Свой ID устройства, счётчики трафика из движка, а не нарисованные.

**Zapret рядом**
- Приложение читает состояние чужого `winws2` и никогда его не трогает.

## 0.4.0

- Режим «Только выбранные» и честный отказ при пустом списке.

- Реальные счётчики трафика через API движка.
- DNS-сервер туннеля, отметка мёртвых серверов, сворачивание в трей,
  редактируемый ID устройства, память пресета Zapret.
